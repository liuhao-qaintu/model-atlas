# 首批资料清单

固定版本的原论文、官方文档和作者实现入口见下表。原始文件按需获取，来源链接不代表已经入库。

## 1. 收录主题与顺序

第一组：1D CNN、2D CNN（以 LeNet 教学结构为例）、ResNet-18、Autoencoder。

第二组：LSTM、Transformer、ViT、CLIP。

第三组（论文应用案例）：DETR、原始LLaVA、DINOv2，分别展示检测、视觉语言生成与视觉表示的模型组合。

第四组：Mamba、Mamba-2、Mamba-3、SigLIP 2、DINOv3，补状态空间演进、图文配对训练和密集视觉表示；按固定论文版本整理。

目前共16个主题，包含架构家族、具体模型与方法。它们不是统一层级的分类，也不标为当前所有任务的最优模型。

## 3. 每个主题整理什么

每个主题先准备概览、原理、输入输出、最小实现、相关模块与来源。公式和图示只有在有依据时加入；应用论文中的模型组合单独记录。

先完成可用的主题内容，再扩充论文数。无需把每份资料全文重复放入每张模型卡；通过来源 ID 和章节位置关联即可。

## 4. 论文发现入口

[Semantic Scholar API](https://api.semanticscholar.org/api-docs/) 可辅助找到论文元信息、参考文献与引用关系。它不计入上面的模型内容来源；发现引用后仍需阅读方法或实现，核实是否实际采用模型。

本轮没有收录未经核查的故障诊断应用关系。后续采用每个重点主题少量代表应用论文，整理实际输入、使用模型、融合步骤与输出，不强制记录实验准确率。
