# DINOv2：ViT 自监督特征与下游任务

模型 ID：dinov2。固定依据：2304.07193v2，2024年论文版本。本卡关注特征来源、输出与下游连接，不比较任务指标。

## 概览与核心机制

DINOv2采用ViT作为纯视觉骨干，通过图像自监督预训练获得可迁移特征。训练处理图像视图与遮蔽 patch，没有以配对文本作为预训练监督；这与 CLIP 的图文对比目标不同。[S34：§4](https://arxiv.org/pdf/2304.07193v2#page=5)

DINOv2 的 ViT 骨干读出全局与局部视觉特征，下游任务头把这些表示映射为具体任务输出。

方法组合图像级 DINO 目标、patch级 iBOT 目标和特征正则化等机制。训练目标中的 prototype scores 不是用户下游任务的固定类别标签；拿到表示后仍需选取合适的任务接口。

## 输入输出与数据流

| 位置 | 输入/输出 | 用途 |
|---|---|---|
| 预训练输入 | 同一图像的多个裁剪/增强视图 | 图像自监督；不是图像＋文字 |
| ViT 骨干输出 | class token与patch token表示 | 全局与局部视觉特征 |
| 图像级特征 | 可用 `[B,D]` 表示 | 分类、检索等下游读取 |
| patch级特征 | 可用 `[B,P,D]` 表示 | 保留空间区域信息，供密集任务使用 |
| 下游输出 | 类别、分割类别图或深度图等 | 由具体任务头与读出流程确定 |

上面的 B、P、D 是本卡用于解释表示的符号；具体尺寸随骨干和图像分辨率变化。D是特征维数，不是用户任务的类别数。DINOv2骨干给出视觉特征，不会仅凭一个特征向量自动得到任意任务的完整答案。[S34：§7.1、§7.4](https://arxiv.org/pdf/2304.07193v2)

## 核心公式

视觉自监督蒸馏使用图像视图形成目标。基础自监督过程中，student 通过目标函数更新，teacher 采用过往 student 参数的指数移动平均。图像级目标对齐不同图像视图的 class-token 分布；patch级目标对齐 student 遮蔽位置与 teacher 可见对应位置的分布。[S34：§4](https://arxiv.org/pdf/2304.07193v2#page=5)

论文还区分大模型到小模型的蒸馏：这一阶段采用更大的冻结 teacher，并保留 student 的 EMA 作为最终模型。不要把基础预训练的 EMA teacher 与这个蒸馏阶段的冻结 teacher 混成一个规则。[S34：§5，模型蒸馏](https://arxiv.org/pdf/2304.07193v2#page=7)

## 与相关模型的联系

DINOv2 的 ViT 骨干产生全局与局部视觉token。DINOv2的视觉骨干属于ViT架构家族，训练目标与普通有监督图像分类不同。class token 和 patch token 的共同结构不意味着加载了本库 TinyPatchViT 的权重，也不意味着输出本库示例的10类分数。[S34：§4](https://arxiv.org/pdf/2304.07193v2#page=5)

在模型组合里，DINOv2作为视觉表示骨干，任务头负责把表示映射为目标任务输出。全局与局部特征可用于不同读出方式；不同下游配置需要对应训练或标注，不能把“冻结骨干”误解成“全部模块无需训练”。

## 应用流程与使用边界

分割与深度读出连接特征与专门的任务头。原论文使用冻结特征进行分类与密集预测评估；分割和单目深度通过特定读出层或解码器得到输出。下游头与读出流程负责产生像素级分割或深度结果，骨干的 patch 特征本身不是已经完成的分割掩码或深度图。[S34：§7.1、§7.4](https://arxiv.org/pdf/2304.07193v2#page=15)

本案例没有运行预训练权重、分割或深度推理，没有复现实验分数，也没有验证任何故障诊断数据集。它提供的是“输入图像→视觉表示→下游任务读出”的知识结构。
