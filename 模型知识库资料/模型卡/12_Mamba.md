# Mamba：选择性状态空间序列模型

模型ID：mamba。依据2312.00752v2（2024-05-31修订；初次发表于2023-12-01）。本卡解释原始方法，不将其称为当前所有任务的最优模型。

## 概览与核心机制

Mamba使用选择性状态空间模型，将部分状态空间参数变成当前输入的函数。直观理解是：状态保留过去的信息，同时根据当前内容决定忘记和写入什么。它的核心序列混合器不是全局softmax自注意力。[S38：§3.2–3.4](https://arxiv.org/pdf/2312.00752v2#page=5)

## 输入输出与数据流

### 条件与易错点

区分接口和数学记号：若词表投影使用PyTorch 2.6的 `nn.Linear(in_features=D, out_features=V)`，其weight参数的存储形状是 `[V,D]`，前向按输入乘weight的转置得到 `[B,L,V]`；数学中将右乘矩阵记为 `[D,V]` 是另一种转置约定。这个条件说明不意味着原Mamba作者必然使用该具体模块。[PyTorch 2.6 Linear.weight](https://github.com/pytorch/pytorch/blob/v2.6.0/torch/nn/modules/linear.py)

本卡用B表示批次、L表示序列长度、D表示模型通道数，说明一般序列模块接口，不固定作者某个检查点的配置。

| 位置 | 形式 | 含义 |
|---|---|---|
| 模块输入 | `[B,L,D]` | 已编码的逐位置特征；文字token需先嵌入 |
| 内部状态 | 状态维数N与内部通道 | 用于记忆，不是N个类别 |
| 模块输出 | `[B,L,D]` | 逐位置表示，仍不是词或类别概率 |
| 语言模型任务头 | `[B,L,V]` | 需额外词表投影；V是词表大小 |

原论文研究语言、音频和DNA序列等设置；不同数据需要各自编码、目标与任务头。把振动序列编码后接入是一种研究方向，不能只凭论文名称宣称已验证故障诊断性能。

## 核心公式

用单通道简化记号说明离散递推：

$$
h_t=\bar A_t h_{t-1}+\bar B_t x_t,\qquad y_t=C_t h_t.
$$

输入相关的步长、B和C带来选择性；A的参数化与离散化须按固定实现核对。这个式子解释状态流，不是完整CUDA内核。[S38：§2、§3.2](https://arxiv.org/pdf/2312.00752v2#page=3)

## 最小代码

原创结构伪代码，不是可以直接调用的作者API；没有执行或下载模型权重。

```text
u, gate = input_projection(sequence)
u = activation(short_causal_conv1d(u))
delta, B, C = input_dependent_parameters(u)
y = selective_scan(u, delta, A, B, C)
output = output_projection(y * activation(gate))
```

## 与相关模型的联系

原始Mamba块包含短一维卷积、选择性SSM、门控和输入输出投影。卷积承担局部处理，状态空间扫描承担序列信息混合；存在Conv1d不意味着它等同于普通CNN分类器。与LSTM都能用状态描述历史，但更新方程和并行算法不同。[S38：§3.4、Fig.3](https://arxiv.org/pdf/2312.00752v2#page=8)

## 应用流程与使用边界

选择原始数据编码→序列骨干→任务头→明确目标。模块输出是特征；直接做故障类别预测还需要分类读出与对应训练。原论文中的性能结论只在其配置与数据下成立，不能自动转成当前硬件延迟承诺。
