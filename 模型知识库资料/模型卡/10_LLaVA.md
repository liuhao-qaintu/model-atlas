# LLaVA：视觉编码器连接语言模型

模型 ID：llava。固定依据：Visual Instruction Tuning，2304.08485v2。这里解释原始 LLaVA 的线性投影设计，不混用后续同名版本。

## 概览与核心机制

LLaVA将CLIP视觉编码器、可训练投影层和Vicuna语言模型连接起来，根据图像与语言指令生成文本回答。图像不是先变成一个类别标签再交给语言模型。[S33：§4.1](https://arxiv.org/pdf/2304.08485v2#page=4)

LLaVA 的 CLIP 视觉分支负责网格编码，LLaVA 原始投影层负责对齐嵌入维数，Vicuna 语言模型负责条件生成。

原论文选择 CLIP ViT-L/14 视觉编码器，使用网格特征形成一段视觉 token；投影层对齐语言模型的词嵌入维数。它不是把 CLIP 的图文相似度矩阵直接当成问答答案。

## 输入输出与数据流

| 位置 | 本案例的输入/输出 | 含义 |
|---|---|---|
| 用户输入 | 图像＋文本指令/问题 | 两种模态，不是图片的RGB三通道 |
| 视觉编码器 | 网格视觉特征 `Z_v` | 一段空间 token 的表示，不只一个整图类别分数 |
| 连接投影 | 视觉 token `H_v` | 与语言模型词嵌入的维度相同 |
| 语言模型输入 | 视觉 token＋文本 token＋历史 | 用于条件生成；多轮问题保留对同一图像的条件 |
| 最终输出 | 生成的回答文本/token序列 | 不是 CLIP 的 B×K 匹配矩阵 |

原始LLaVA用线性投影把视觉token映射到Vicuna的词嵌入空间。若用 `[B,P,D_v]` 表示网格特征，投影后可表示为 `[B,P,D_lm]`；这里的 B、P 和维数是本卡为解释接口引入的符号，具体预处理和 token 数须按选定版本核对。[S33：式1](https://arxiv.org/pdf/2304.08485v2#page=4)

LLaVA 原始投影层保留视觉 token 序列，只对每个 token 的特征维度进行线性映射。

## 核心公式

论文的连接关系为：

$$
Z_v=g(X_v),\qquad H_v=W\cdot Z_v
$$

`g` 是视觉编码器，`W` 是可训练投影，`H_v` 是对齐后视觉 token。公式采用论文的记号约定；不能只看矩阵乘号就推断某个框架的 batch/token 轴排列。[S33：§4.1，式1](https://arxiv.org/pdf/2304.08485v2#page=4)

原论文描述两阶段：第一阶段冻结视觉编码器与语言模型，只更新投影矩阵；第二阶段保持视觉编码器冻结，更新投影与语言模型。第二阶段的“端到端微调”不等于所有模块都解冻。[S33：§4.2](https://arxiv.org/pdf/2304.08485v2#page=5)

## 最小代码

以下是本卡的结构伪代码，不是作者完整实现，也不是可直接运行的推理服务。

```text
visual_grid = CLIP_visual_encoder(image)
visual_tokens = linear_projection(visual_grid)
text_tokens = language_tokenizer(question_and_history)
answer = Vicuna_generate(visual_tokens, text_tokens)
```

原文讨论视觉网格层的选择；直接拿官方 `CLIP.encode_image` 返回的整图共享表示替换全部视觉 token，不能据此声称复现了该架构。

## 与相关模型的联系

LLaVA 的 CLIP 视觉分支产生网格表示，由连接器传给语言模型。LLaVA的视觉分支来自CLIP预训练模型，具体选择ViT-L/14。CLIP是视觉编码器的预训练来源，LLaVA不使用CLIP文本塔产生回答；文本回答由 Vicuna 语言模型生成。[S33：§4.1](https://arxiv.org/pdf/2304.08485v2#page=4)

原始连接器是线性投影层，用于视觉token到语言嵌入的维度对齐，执行的是线性映射；不是完整的图文对比损失，也不是本库 ViT 的整图分类头。不同结构中出现 Linear，只能据各自输入输出和任务比较，不能推断权重或功能完全相同。

## 应用流程与使用边界

图像与语言指令进入模型，回答以文本形式输出，可用于图像描述、多轮视觉问答及原论文的 ScienceQA 场景。[S33：§4.2](https://arxiv.org/pdf/2304.08485v2#page=5)

本案例只是该方法的知识检索资料；本 RAG 平台没有部署 LLaVA，也没有新增图片上传理解接口。原论文两阶段训练是知识点，本轮没有执行模型训练或评测视觉问答准确率。
