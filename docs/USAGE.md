# 使用流程

## 学模型与追问

登录后从“学模型”打开AE、CNN或Transformer等条目。先看输入输出和结构，再按需要展开公式或代码。“问这一节”将当前章节作为上下文，继续提问沿用当前会话；引用编号可展开原文节选与来源。

## 导入和阅读文献

在“我的文献”选择文件、预览解析结果并导入。这里仅列出本人上传或导入的资料，可按标题、文件名和标签查找。公共参考来源在模型内容及回答引用中按需查看，不单独列成目录。

切片在后台完成。仅本地处理的资料用于本地检索；主动允许云端处理后，才能调用模型生成分析报告、向量、重排和回答。报告用于梳理主题、方法、创新点和依据，标签与关系确认后写入图谱。

PDF文字提取不还原论文排版；章节、页码和解析段落用于定位。公式、图表与实验结论通过原文件核对，扫描件需先完成OCR。

## 比较研究

提出包含比较对象与维度的问题，选择可用于云端处理的资料。系统拆解查证项、检索并按缺口补查，返回带引用的结果。之后可进入同一研究结果对应的会话继续问答。

## 维护

管理员需额外进入本地维护白名单才能使用评测和审核工具。评测题集属于开发材料，机器建议不能直接当作人工核验结果。管理员也不能默认查看其他用户的私有资料。
